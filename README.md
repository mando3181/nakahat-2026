# داشبورد فروع الكافيهات 2026 — نكهات مختصة للتجارة

لوحة تفاعلية لقوائم الدخل الشهرية للفروع (يناير–سبتمبر 2026). ملف واحد مستقل: `index.html`
(البيانات مدمجة داخله، ويحتاج اتصال إنترنت لتحميل Chart.js وFont Awesome وخط Tajawal).

## التشغيل
افتح `index.html` في المتصفح، أو فعّل GitHub Pages من إعدادات المستودع (Branch: main / root).

## تحديث الداشبورد لشهر جديد
1. ضع ملفات الشهر (zip لكل شهر فيه «مجمع الفروع» وقوائم الفروع) في مجلد `قوائم دخل الفروع` كما هو.
2. عدّل المسارات أعلى `build/build_nakahat.py` (BASE) لتناسب جهازك، ثم:
   ```
   python build/build_nakahat.py          # يكتب data.json و audit.json بعد المطابقة
   python build/build_html.py data.json "داشبورد فروع الكافيهات 2026 — نكهات مختصة" "نكهات مختصة للتجارة" index.html
   ```
المطلوب: Python 3 مع openpyxl، وNode.js لفحص الصياغة (اختياري).

## الهيكل
- `index.html` — الداشبورد
- `build/build_nakahat.py` — استخراج البيانات ومطابقتها مع قوائم الفروع وتوليد الملاحظات
- `build/build_html.py` + `build/assets/` — دمج البيانات مع القالب والفحص

## تنبيه
الداشبورد يحتوي بيانات مالية فعلية للشركة. استخدم مستودعًا **خاصًا (Private)**، ولا تفعّل Pages إلا إن كان النشر العلني مقبولًا.
